# Accessibility and Visual Design Update

## Accessibility fixes
- Added a skip link and clear page landmarks so keyboard and screen-reader users can move through the site more easily.
- Added descriptive link text and accessible navigation labels to make the menus easier to understand.
- Added proper form labels, fieldsets, legends, and live error messaging to the contact form so validation is announced accessibly.
- Updated the color palette to use stronger contrast between text and background for better readability.

## Visual design choices
- I used proximity to group related content into clear sections and project cards.
- I used repetition by keeping the same header, card styling, and button treatment across all pages for a consistent experience.
- The palette is consistent across the home, projects, and about/contact pages with sage green, warm cream, and accent orange.
